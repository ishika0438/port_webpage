# Personal Portfolio Webpage

## 📌 Overview
This is a personal portfolio website created to showcase my profile and basic web development abilities.  
It is designed as a multi-section webpage with a clean layout and simple navigation to present information effectively.

## 🔗 Live Demo
https://ishika0438.github.io/port_webpage/

## ✨ Features
- Personal introduction section  
- Structured sections (about, footers, etc.)  
- Clean and minimal UI design  
- Simple navigation across the webpage  
- Beginner-friendly layout  

## 🛠️ Tech Stack
- HTML  
- CSS
  
## 🎯 Purpose of the Project
This project was built to practice frontend development and understand how to design and structure a very basic beginner friendly personal portfolio website.

## 🎨 Design Approach
- Simple and clean layout  
- Focus on readability  
- Organized sections for better user experience  
- Basic styling and alignment  

## 📚 What I Learned
- How to structure a full webpage using HTML  
- Styling using CSS (layout, spacing, alignment)  
- Creating multiple sections in a single page  
- Basics of UI/UX design  

## 🚀 How to Run Locally
1. Clone the repository  
2. Open `index.html` in your browser
